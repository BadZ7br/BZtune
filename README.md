# BZtune 🎵

> **Nota:** Este projeto é destinado **apenas para fins didáticos e educacionais**. O objetivo é simular um aplicativo de música "gratuito" exclusivamente para testes, aprendizado e desenvolvimento de habilidades técnicas.

---

## 📌 Sobre o Projeto

O **BZtune** é uma aplicação para reprodução e gerenciamento de música desenvolvida com foco em estudo de arquitetura web, separação entre frontend e backend, e integração de APIs.

---

## 🚀 Como Executar o Projeto

Para rodar o BZtune localmente, é necessário abrir **3 terminais distintos** e executar os comandos indicados abaixo para cada serviço.

### 💻 Terminal 1: Frontend (Servidor de Desenvolvimento)

Neste terminal, você iniciará o ambiente de desenvolvimento do frontend.

```bash
cd doomvault
npm run dev
```

---

### 📦 Terminal 2: Frontend (Build)

Neste terminal, você executará o processo de build do frontend.

```bash
cd doomvault
npm run build
```

---

### 🐍 Terminal 3: Backend (API Python)

Neste terminal, você ativará o ambiente virtual (caso ainda não esteja ativo) e iniciará o servidor da API.

```powershell
cd doomvault-api

# Ativar o ambiente virtual (PowerShell no Windows)
.\.venv\Scripts\Activate.ps1

# Iniciar a aplicação
python app.py
```

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** Node.js / JavaScript / React (pasta `doomvault`)
- **Backend:** Python (pasta `doomvault-api`)
