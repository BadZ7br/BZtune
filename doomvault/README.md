# Frontend do BZtune

Este diretório contém a interface React/TypeScript/Vite.

## Executar

```powershell
npm ci
npm run build
npm run dev
```

> É necessário executar o Flask em `../doomvault-api` para buscas, playlists e biblioteca offline.

O CSS foi consolidado em **`src/styles.css`**. Não importe folhas CSS individuais em componentes.

Veja [o README principal](../README.md) e [a arquitetura](../docs/ARQUITETURA.md).
